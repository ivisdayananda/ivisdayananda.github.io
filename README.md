# Dayananda A. — Developer Portfolio

A responsive, single-page portfolio for Full-Stack Development and Generative AI opportunities.

## Files
- `index.html` — portfolio content and structure
- `style.css` — responsive visual design
- `script.js` — mobile navigation and reading progress
- `portfolio.pdf` — matching portfolio document

## Run locally
Open `index.html` in a browser. No build step is required.

## Publish with GitHub Pages
1. Create a repository (for example, `ivisdayananda.github.io`) or use an existing portfolio repository.
2. Upload `index.html`, `style.css`, `script.js`, and `portfolio.pdf` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Choose deployment from the `main` branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish the site.

## Before sharing with recruiters — important verification checklist
- Confirm your displayed name and preferred professional title.
- Add a professional email address and (optionally) phone number.
- Add direct repository links for each featured project; do not link a project to the profile root as if it were its source repository.
- Add live demos only when publicly accessible and working.
- Add real screenshots, architecture diagrams and short demo videos.
- For the AI/ML certification, add exact course title, provider, completion date and credential URL/ID.
- Verify project status and the exact technology stack. The website deliberately marks the MERN Student Management System as in progress and keeps proposed ideas out of the completed-project list.
- Add measurable outcomes only when you have evidence. Never invent users, accuracy, speed, revenue, deployment or performance metrics.

## Portfolio PDF
Keep `portfolio.pdf` in the same directory as `index.html` so the website's download link works.
